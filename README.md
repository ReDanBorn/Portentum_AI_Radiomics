# Portentum_AI_Radiomics

Что необходимо для запуска приложения:

1. Установить библиотеки через терминал или самостоятельно (список библиотек в файле all_requirements.txt)

...```pip install -r all_requirements.txt```...

2. Запустить приложение строго через терминал

...```python -m streamlit run app.py```...
